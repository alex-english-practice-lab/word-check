# Single Meaning · Part of Speech and First Letter

New free Single practice displays one Chinese sense, the word entry's existing part of speech, and by default the first English letter. The checkbox can suppress the letter without affecting the part of speech. Full practice retains its existing phonetics, part of speech and complete senses. A one-letter English target does not display its entire answer. A phrase displays only its first English letter; no other letters or length placeholders are added. If source POS is empty, the prompt says `词性未提供`. The source schema has only a word-level POS, so `n. / v.` stays combined rather than guessing a POS for a specific sense.

At `begin`, the quiz shuffles the selected words and materializes exactly one prompt per question via `WordCore.spellingPrompt`. Both the displayed question and `PracticeAttempt.questions[].prompt` receive this exact object. A new Single prompt has `format: 'single-cue-v1'`, `initialShown: boolean`, and `initial: string` (empty if not shown). The Question already stores `mode`. `Answer.response.hintCount` and `spellingChecks` start at zero; the preprinted first letter does not change grading. The result page notes the cue, and the teacher dashboard reads it from the submitted Question snapshot. Existing terminal and cloud records retain their original snapshots.

New Single teacher links store an optional `i` boolean (compact `0/1` in v3 and v7) across fixed v3, random v4, scoped random v6 and Learning v7; Cloud Assigned links wrap those tokens unchanged. New Full links do not contain `i`. Existing v1–v7 links **without** `i` run the legacy Single prompt: one Chinese meaning and no POS or initial. Existing tokens and history are not rewritten. When the student restarts a random preset, the same configuration selects a new pool and materializes fresh prompts.

The local Learn setup has no Final Check cue selector in this phase. New personal Learning Packs default to the Single cue; packs saved before the update without `showFirstLetter` retain the old prompt. Learning Assignment teacher settings have their own checkbox when Final Check mode is Single.

The backend stores client-reported attempts, not server-graded facts. The initial does not provide identity verification. The existing quiz ends an interrupted attempt and starts a fresh one on reload rather than resuming an unanswered question in place; the original saved attempt keeps its original prompt.
